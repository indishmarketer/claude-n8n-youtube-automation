# Example Scripts

**Replace this entire file with two or three of your own scripts before you run the system.**

This is the highest leverage file in the repo. Claude matches what it sees here. If this file is empty or generic, your scripts will sound generic.

## What to put here

- Two or three complete scripts you actually published
- Pick ones you were happy with
- Include the hook exactly as you delivered it
- Keep the filler, the asides, the way you actually phrase things

## What not to put here

- Someone else's script
- A script you wrote to sound impressive rather than how you talk
- Outlines. Full scripts only.
